## 1. 先看结论

你需要的不是把桌面网页缩小到手机屏幕，而是：

**将现有教材下载工具重写为可独立安装和运行的 Android App，保持国家智慧教育平台教材获取、分类选书、批量下载、书架管理的业务规则，以及纸张质感、低饱和色块、方线书本图形、晨光/夜读双主题；将导航、触摸、返回、权限、文件管理和后台任务改造成 Android 用户熟悉的方式。**

**已确认采用 Kotlin + Jetpack Compose 原生安卓应用**，直接在手机访问现有上游数据源，不运行 Go 本地 HTTP 服务、不要求用户安装桌面 Chrome 或配置命令行工具。用户于 2026-10-31 明确同意六项推荐决策，详见 §5；这表示产品方向已确认，不表示登录、后台执行或上游续传条件已经通过技术验证。

首要技术风险不是界面，而是 **平台是否允许且能在 Android 上完成登录授权并获得下载所需凭据**。桌面代码通过 Chrome 自动化读取登录网页的本地存储；系统浏览器/Custom Tabs 不允许 App 任意读取它们的存储，不能直接照搬。应先做授权与下载纵向验证，再全面开发。

## 3. 哪些已经确定，哪些还没有

### 已明确的用户要求

1. App 叫 **TextbookGo**。
2. 项目叫 **TextbookGo-Mobile**。
3. 将当前多平台程序重写成 Android App。
4. 业务逻辑和界面风格保持一致。
5. 交互符合安卓操作逻辑和习惯。
6. 先整理清楚需求并提供可执行文档，而不是直接堆功能。

### 本文使用的标记

- **[现状]**：源码中已存在，带可追溯依据。
- **[要求]**：你已明确提出。
- **[已确认]**：用户明确接受的决策，作为当前首版范围基线。
- **[建议]**：实施细节或后续增强建议，不自动等于已批准需求。
- **[待确认]**：影响范围、架构或验收的产品决策。
- **[修复]**：不改变产品目标，但不应保留的旧实现缺陷。

“业务逻辑不变”解释为保持用户目标、教材分类规则、下载资源选择优先级、完成去重和书架语义，不表示保留错误、明文凭据、桌面依赖或不可恢复的进度流。

## 4. 首版范围基线（按已确认决策收敛）

以下由既有功能保留要求和 Q1–Q6 确认结果形成；页面微交互、技术参数及未覆盖事项仍按各文档标记处理。

**首版必须完成：**

- 登录/授权与目录预检；有凭据不等于已确认有效。
- 年级 → 学科 → 教材，书名搜索，多选、清空、批量下载。
- 保留跨学科/年级选择，按教材 ID 全局去重；解决旧版计数和提交不一致。
- 默认最多 3 本并发，流式下载，主/备链接，后台继续、失败重试、取消、网络恢复，以及单任务暂停/恢复与可靠断点续传。
- 续传须满足服务器 Range 与资源身份校验条件；不支持或验证器变化时明确提示并安全从头下载，不承诺任意来源都能续传。
- 已完成文件不重复下载；临时文件不冒充成功；完整性校验后入书架。
- 书架、封面/拼贴占位、文件信息、删除确认。
- 下载进度在应用内和系统通知可见，切页/旋转/进程重建不丢任务事实。
- 晨光/夜读主题、记住登录状态、App 内保存＋按需导出、系统 PDF 打开/分享、隐私与开源说明。
- Android 8.0/API 26 起，手机优先，横屏/平板保证基本可用；以签名 APK 自用/小范围内测作为首版交付。

**不默认加入首版：**内置 PDF 阅读器、笔记批注、OCR、云同步、自建账号系统、教材镜像服务器、iOS、支付/广告、全局跨学科搜索、旧桌面数据自动迁移。

**可选兼容项：**把上游目录写入 PDF 书签是旧版的可选能力，需要单独验证安卓 PDF 写入库的兼容性和许可。它不是“阅读器收藏夹”，不能在文档里偷换概念。

## 5. 已确认的 6 项决策

确认日期：**2026-10-31（Asia/Shanghai）**。确认依据：用户明确回复“按照你的建议来，这6个我都同意了，加到文档里，完善文档即可”。

| 编号 | 已确认决定 | 范围与验收影响 | 状态 |
|---|---|---|---|
| Q1 | Kotlin + Jetpack Compose 原生重写，不做整站 WebView 套壳 | Android 页面/业务原生实现；授权页可在合规且验证通过后使用专用 WebView，不等于套壳 | 已确认 |
| Q2 | Android 8.0/API 26 起，手机优先 | 横屏/平板基本可用必测；平板双栏等增强后续做；target/compile SDK 另行锁定 | 已确认 |
| Q3 | 首版不内置 PDF 阅读器 | 调用系统阅读器；无处理应用时可导出/分享，不能崩溃 | 已确认 |
| Q4 | App 内保存＋按需导出 | 内部主文件随卸载删除，首次下载/设置中说明；独立导出副本不随删除主文件连带删除 | 已确认 |
| Q5 | 首版支持后台继续、失败重试/取消、暂停/恢复与可靠断点续传 | 合规后台受系统约束；具备 Range/验证器条件才追加，不满足则明确从头；暂停/续传纳入 P0 与验收 | 已确认 |
| Q6 | 先提供 APK 自用/小范围内测，PDF 目录书签为可选增强 | 首版签名 APK 为必需；公开商店上架、AAB、PDF 书签不作为首版发布门槛 | 已确认 |

Q1–Q6 无需再次询问。未确认的 Q7–Q10 等交互细节保留为独立事项，见 [产品需求 §9](<02-产品需求与安卓交互规范.md#9-决策记录与剩余事项>)，不因本次同意六项而默认为全部批准。
