## 2. 真实功能清单

### 2.1 登录与目录预检

1. 首页读取历史数量与“是否存在 token”，**未联网验证 token 有效性**，见 [home.go:8–19](<../../internal/app/home.go#L8-L19>)。
2. 点击“登录并预检目录”调用目录业务；先从 `SMARTEDU_TOKEN` 环境变量或用户配置中取 token，不存在才打开 Chrome。
3. 当前登录实现无论是否 Quiet 都先等待约 10 秒，以临时 Chrome profile 导航至 `https://auth.smartedu.cn/uias/login`，总超时 5 分钟，每 2 秒读一次当前页面 localStorage。
4. 寻找键名前缀 `ND_UC_AUTH`，先解析外层 JSON，再解析 `data.value` 字符串，读取 `access_token`。不收集 App 自己的账号密码。依据 [login.go:37–169](<../../internal/auth/login.go#L37-L169>)。
5. token 明文保存到用户目录 `.config/BoooookDown/token.json`，字段 `token/saved_at/updated_at`。旧名称不是安卓包名需求。
6. 拉取目录后，按标题、ID 取稳定样本请求资源详情做鉴权预检；没找到年级则失败。见 [app/catalog.go:12–36](<../../internal/app/catalog.go#L12-L36>)。
7. HTTP 401 最多触发一次重新登录后重放；并发刷新互斥，有其他请求已经刷新则复用。它不是 OAuth refresh token 协议。见 [client.go:118–155](<../../internal/api/client.go#L118-L155>) 和 [session.go:37–62](<../../internal/auth/session.go#L37-L62>)。

### 2.2 分类、搜索、多选

- 从目录条目的标签生成年级和学科，并不是主流程先加载标签树。
- 年级顺序：一年级至九年级、高一至高三；未知年级追加，但旧版 map 遍历使追加顺序不稳定。
- 年级和学科筛选使用标签名 `contains`，不是按 tag ID 精确相等。学科 `sort.Strings` 排序（UTF-8 字符串顺序，不是中文拼音排序）。见 [api/catalog.go:93–199](<../../internal/api/catalog.go#L93-L199>)。
- 教材未下载排在已下载前，其后按标题排序；版本、册次来自 `zxxbb/zxxcc`。见 [app/catalog.go:45–63](<../../internal/app/catalog.go#L45-L63>)。
- 书名搜索仅在**当前年级、当前学科**列表内，trim 后转小写做子串匹配，不请求后端搜索。切分类不会主动清空搜索词。
- 选择状态是内存中的 ID 集合，可以在切分类时保留；但真正提交只遍历当前年级，这是旧缺陷，不应作为产品规则。见 [app.js:105–153](<../../webui/frontend/js/app.js#L105-L153>)。
- 可选择“已下载”卡片，执行下载时再次检查历史和文件，存在则跳过，不应重新传输。

### 2.3 下载

- 默认最大并发为 3；请求详情 → 解析主/备链接 → 下载 → 写历史 → 完成事件 → 可选写 PDF 书签。见 [app/download.go:15–69](<../../internal/app/download.go#L15-L69>)。
- 资源候选顺序：① `ti_is_source_file=true` 且非 `ebook_mapping`；② `ti_format=pdf/PDF`；③任意非映射且有存储地址的条目。第一类不保证真是 PDF，Android 必须验证内容类型/文件头，不能只改扩展名。见 [resources.go:27–74](<../../internal/api/resources.go#L27-L74>)。
- 主地址模板映射私有/公开 CDN；备用链接取 `ti_storages` 第一个非空值，否则尝试替换 s-file 域名。对私有下载域名，域名替换可能返回原地址，因此不保证备用是独立服务器。
- 32 KiB 流式缓冲，约每 100ms 报进度；没有把 PDF 整体读入内存进行下载。
- 临时后缀 `.tmp`，完成后重命名；文件名由标题替换非法字符得到，没有用 ID 防止同名覆盖。
- **不是可靠断点续传**：发现旧临时文件时直接追加，但请求没有 Range；再次下载可能把完整新响应接在旧文件后，产生损坏。
- 文件客户端 HTTP 总超时 60 秒；大文件/弱网可能在中途失败。没有真正可取消的 HTTP 请求上下文，UI 无暂停/取消入口。
- 事件流断开不表示下载停止；服务端使用独立 background context。SSE 一次取走 stream，不支持持久进度、重放或进程恢复。

### 2.4 书架和设置

- 书架是下载历史条目，没有内置阅读器，也没有点击卡片打开 PDF 的处理。
- 每成功一本重新加载书架；书架可见时约每 3 秒轮询。新书落架有轻量动效，空书架使用几何插画。
- 拖动书到垃圾区立即删除文件与记录，没有二次确认；Android 应替换成长按/菜单 + 确认。
- 访问书架时核对历史指向文件是否存在，清理缺失记录；不反向扫描任意 PDF 自动导入。所谓“双向同步”实际只覆盖“已记录文件消失”的一侧，且把所有 stat 错误都当缺失。见 [webapp.go:61–75](<../../internal/webapp/webapp.go#L61-L75>)、[history.go:166–189](<../../internal/download/history.go#L166-L189>)。
- 选书页优先使用平台封面；没有源时，已下载尝试本地 PDF 封面，否则使用 6 种哈希拼贴。图片失败直接显示拼贴，不会自动依次请求所有封面源。书架封面直接尝试本地 PDF。见 [render.js](<../../webui/frontend/js/render.js>)、[ui.js:104–122](<../../webui/frontend/js/ui.js#L104-L122>)。
- 本地 PDF 首页渲染只在 Windows 实现，其他平台主动降级。Windows 封面会读取整个 PDF 到内存，不能把“流式下载低内存”误扩展成“整套程序永远固定内存”。
- 设置有“记住登录状态”（默认开）、“下载后自动打开目录”（默认关）、打开下载目录。没有选择/修改下载目录的 UI。
- 外观有晨光/夜读；切换时未写回 localStorage，刷新后不保证保持。点击音来自 Web Audio，不能据此要求安卓强制每次点按出声。

## 3. 上游数据契约（依据源码，未在线探测）

### 3.1 请求位置与含义

基础服务器随机取 `s-file-1/2/3.ykt.cbern.com.cn`，统一 HTTPS。完整定义见 [endpoints.go:7–69](<../../internal/api/endpoints.go#L7-L69>)。

| 数据 | 路径/来源 | 内容 |
|---|---|---|
| 数据版本 | `/zxx/ndrs/resources/tch_material/version/data_version.json` | `module`、`module_version`、`urls` |
| 教材分片 | 版本响应 `urls` 中地址 | `CatalogEntry[]`，最多 5 个并行获取 |
| 标签树（非主流程必需） | `/zxx/ndrs/tags/tch_material_tag.json` | 标签层级 |
| 资源详情 | `/zxx/ndrv2/resources/tch_material/details/{contentId}.json` | `ti_items` 等 |
| PDF/源文件 | `ti_storage` 模板或 `ti_storages[]` | 字节流 |
| 电子书映射 | 详情中 `ti_file_flag=ebook_mapping` 对应文件 | `ebook_id`、`mappings[]` |
| 目录树 | `/zxx/ndrv2/national_lesson/trees/{ebookId}.json` | `TreeNode[]` |

重要字段：

- `urls` 是**逗号分隔字符串，不是 JSON 数组**。
- `ti_storages` 是**字符串数组，不是对象数组**。
- `ti_size/module_version` 使用 64 位类型；总长度未知需允许 `null` 或明确未知态。
- 标签使用 `tag_list[]`，含 `tag_id/tag_name/tag_dimension_id`；维度 `zxxxd/zxxnj/zxxxk/zxxcc/zxxbb`。
- 目录封面优先 `custom_properties.thumbnails[0]`，回退 `preview["Slide1"]`。
- `TiItem` 定义了 `ti_md5`，但旧下载逻辑没有做 MD5 校验。
- 映射页码缺失时为 0；目录源页码基准必须用真实样例确认，不能未经验证直接换成 PdfRenderer 的 0-based 索引。

模型依据：[models/catalog.go](<../../internal/models/catalog.go>)、[api/bookmarks.go](<../../internal/api/bookmarks.go>)。

### 3.2 鉴权与链接

```http
X-ND-AUTH: MAC id="<access_token>",nonce="0",mac="0"
```

模板 `cs_path:${ref-path}` 或 `${ref-path}` 替换为：

- 有 token：`https://r1-ndr-private.ykt.cbern.com.cn`
- 无 token：`https://c1.ykt.cbern.com.cn`

JSON 请求最多 3 次尝试，网络/读取/5xx 可重试，非 200 非 5xx 返回错误；401 走一次重新授权。代码采用桌面 UA，不代表上游 Android 强制要求这个 UA。Android 应以 PoC 观察到的合法兼容配置为准。

[修复] 旧 client 给所有请求附 token，且分片/备用 URL 可由外部 JSON 返回；安卓版必须对 URL 和重定向做 HTTPS 与精确主机白名单检查，并用独立鉴权/公共图片 client，不能把凭据发往任意地址。

### 3.3 当前本地 API 能力映射

这是桌面本地桥接协议，**不是国家平台的服务端接口**。

| 前端使用的方法与路径 | 请求/响应要点 | Android 对应 |
|---|---|---|
| GET `/api/home` | output_dir/logged_in/history_count | 本地设置 + 会话状态 + Room 数量 |
| POST `/api/login` | 无 body；执行目录预检 | AuthorizeAndPreflight |
| GET `/api/catalog` | grades → subjects → books | ObserveCatalog/FilterBooks |
| GET `/api/shelf` | ID、标题、文件名、时间、大小 | ObserveShelf |
| POST `/api/shelf/delete?id=` | 删除文件和历史 | DeleteBook |
| POST `/api/download` | `{ids:[...]}`；返回 stream_id | EnqueueBatch |
| GET `/api/download/stream?id=` | start/progress/done/bookmark/finished/error | Room + StateFlow |
| POST `/api/open-dir` | 调系统文件管理器 | 保存位置/系统文件入口 |
| POST `/api/token/forget` | 删持久 token | SetRememberSession(false) |
| GET `/api/cover?id=` | PNG；缺失 404 | CoverRepository/PdfRenderer |

实际 Go 路由不校验 HTTP 方法，表中方法来自前端调用而非服务端强制保证。参考 [api.js](<../../webui/frontend/js/api.js>)、[handlers.go](<../../internal/server/handlers.go>)。

## 6. 审阅边界与后续基线冻结

- 已静态审阅全部业务源文件；未做真实账号授权、下载、PDF 库运行或视觉截图验证。
- 缺 Go 与默认 Android SDK，不能给出“测试通过”结论。
- 三张原截图仅确认存在，未成功读取像素；视觉事实来自 CSS/HTML/SVG，不猜图片内容。
- Android 开工时从授权的测试账号录制去敏样例：版本、至少两片目录、详情、映射、目录树、401/403/429/5xx、200/206/416 文件响应。
- fixtures 不得包含 token、cookie、用户标识、受版权保护 PDF 正文；测试 PDF 应自建，保留完整开源/素材许可说明。
