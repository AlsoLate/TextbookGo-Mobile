# 07 · 应用内 PDF 阅读器设计

> 2026-10-31 修订：原 Q3「首版不内置阅读器」改为内置阅读器。书架点击教材直接阅读，
> 系统 `ACTION_VIEW` 保留为“用其他应用打开”入口。

## 1. 目标与范围

| 项目 | 做法 |
|---|---|
| 入口 | 书架整张卡片可点；溢出菜单「打开」；菜单另保留「用其他应用打开」 |
| 渲染 | `android.graphics.pdf.PdfRenderer`（API 21+，minSdk 26），不引入第三方 PDF 引擎 |
| 阅读方式 | 竖向连续滚动，页面按屏宽等比缩放，页间留白 + 纸面白底 |
| 缩放 | 双指捏合 1×–4×，双击 1× ↔ 2.2×，放大后单指拖动平移；“复位”浮层一键还原 |
| 翻页 | 底部滑块、上一页/下一页、页码弹窗输入跳转 |
| 夜读 | 纸面颜色反相 + 阅读器局部切换暗色主题（顶栏、菜单、弹窗一起变暗） |
| 进度 | 按教材 id 记录页码，重新打开自动续读；删除教材时清理进度 |
| 常亮 | 进入阅读器 `keepScreenOn = true`，退出恢复 |

不做的：文本选择/搜索/复制、书签目录写入、批注、加密 PDF 解密、页面预渲染全本。

## 2. 渲染管线

`ui/reader/PdfBookDocument.kt`

- `PdfBookDocument.open(file)`：`ParcelFileDescriptor` + `PdfRenderer`；打开时一次性读取每页
  `height / width`，渲染前用比例占位，滚动时页面高度不跳动。
- `render(page, widthPx)`：按 `widthPx` 等比创建 `ARGB_8888` 位图，先铺白底再
  `Page.RENDER_MODE_FOR_DISPLAY`（PdfRenderer 不铺底，透明区域在深色背景上会变黑块）。
- `PdfPageCache`：`LruCache<Int, Bitmap>` 按字节淘汰，默认 40 MB；按屏幕宽度 1.25× 渲染，
  保证文字经缩放后仍然实、放大 1.25× 内清晰，同时控制单页内存。
- 线程模型：`PdfRenderer` 非线程安全，全部渲染挂在
  `Dispatchers.IO.limitedParallelism(1)` 上；退出阅读器时关闭任务也投递到同一调度器，
  保证不会在渲染中途 `close()`。

页面条目用 `produceState` 异步取图：先画白纸占位，缓存命中直接显示；当前页停留 350 ms
后预取下一页，减少翻页空白。

## 3. 手势

`ui/reader/PdfReaderScreen.kt` 的 `detectReaderGesture`：

1. 单指且未放大时**不消费**任何事件，交给 `LazyColumn` 正常滚动。
2. 双指落下后，以“双指距离相对落下时的变化”超过 `touchSlop` 作为启动阈值——
   慢速捏合也能触发（逐帧增量判断会永远达不到阈值，这是调试中修掉的真实问题）。
3. 放大后单指拖动直接消费事件做平移；`LazyColumn` 同时设置
   `userScrollEnabled = !zoom.active` 避免抢滚动。
4. 缩放以双指中心为锚点：`offset' = k·offset + (1−k)(centroid − center)`，并按页面尺寸
   限制平移范围，页面不会拖出边界。
5. 双击在点击位置放大；再次双击或点“复位”还原；返回键在放大状态下先复位、再退出阅读器。

`PageZoomState` 只允许一页处于放大状态，翻页/跳页时自动复位。

## 4. 当前页与进度

- “当前页”取**占视口面积最大**的页，而不是 `firstVisibleItemIndex`。跳到最后一页时
  最后页往往只能贴底显示，取首个可见项会错误停在上一页。
- 进度写入 `SharedPreferences("textbookgo-reader")`：`page:<bookId>`、`total:<bookId>`；
  停留 500 ms 后写一次，退出时再兜底写一次。删除教材时同步 `clear(bookId)`。
- 打开时把记录页码限制在 `0..pageCount-1`，文件被替换也不会越界。

## 5. 夜读

- 页面位图套 `ColorMatrix` 反相（白底→黑底、黑字→白字），由 `Image(colorFilter=…)` 应用。
- 阅读器外层再包一层 `TextbookGoTheme(theme = NIGHT)`，顶栏、底部滑块、菜单、跳页弹窗
  同步变暗；夜读状态是全局偏好，下次打开任意教材沿用。
- 阅读进度与夜读开关分开存储：夜读不随单本书变化。

## 6. 错误与边界

| 情况 | 表现 |
|---|---|
| 文件不存在 | “教材文件不存在，可能已被系统清理，请重新下载。” + 用其他应用打开 / 返回书架 |
| 加密 PDF | “这本 PDF 有密码保护，应用内暂时无法打开。” |
| 损坏/非 PDF | “文件可能已损坏，或不是标准的 PDF。” |
| 0 页 | 走错误页，不进入阅读界面 |
| 渲染 OOM | 渲染失败返回占位白纸，阅读器不崩溃；退出时清空缓存 |

## 7. 内存

- 单页位图 = 页宽 × 1.25 × 页高 × 4 B；1080p 手机约 9 MB/页。
- 缓存 40 MB（约 3–4 页）；退出阅读器 `cache.clear()` 并关闭文档，避免翻书后把几十 MB
  位图留给 GC。
- 实测 1280×2856 模拟器：打开阅读器后 native heap 约 61 MB（含 3 页位图），
  关闭阅读器回落。

## 8. 验收

`android/app/src/androidTest/.../PdfReaderTest.kt`（9 条，全部通过）：

- 打开落在第 1 页、标题正确
- 上一页/下一页
- 单击隐藏/显示顶栏与底栏
- 双击放大出现“复位”，点击复位还原
- 双指捏合放大，再双击复位
- 跳页到第 3 页，关闭再打开仍停在第 3 页
- 夜读开关与菜单文案变化
- 顶栏返回触发关闭
- 菜单存在“用其他应用打开”

不依赖网络、账号与下载流程。
