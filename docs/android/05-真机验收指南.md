# 05 · 真机验收指南（真实平台）

> 目标：用你自己的账号，在真机上完成“登录 → 选书 → 下载 → 书架打开/分享/导出 → 删除 → 重启恢复”的全流程验收。  
> 这份指南只使用 `verify` 构建：真实平台数据 + 调试签名，可直接安装，不与 Debug 示例包冲突（包名后缀 `.verify`）。

## 1. 准备

![应用内登录页](<images/verify-login.png>)

> 上图：verify 包打开的真实平台登录页（已自动修正窄屏布局）。

1. 构建验收包：

   ```powershell
   cd android
   .\gradlew.bat :app:assembleVerify
   ```

   产物：`android/app/build/outputs/apk/verify/app-verify.apk`（约 7.6 MB）。

2. 安装到真机（USB 调试）或直接传到手机点击安装：

   ```powershell
   adb install -r app\build\outputs\apk\verify\app-verify.apk
   ```

   包名：`com.textbookgo.mobile.verify`；可与 Debug 示例包（`com.textbookgo.mobile`）共存。

3. 手机要求：Android 8.0（API 26）及以上；可访问 `auth.smartedu.cn`、`*.ykt.cbern.com.cn`；建议 Wi-Fi。

## 2. 登录

### 2.1 网页登录（推荐）

1. 打开应用 → 下载页显示“登录国家智慧教育平台”。
2. 点击“登录并加载教材”。
3. 在应用内网页中完成平台登录（账号/手机号 + 密码/验证码，按平台页面提示操作）。
4. 登录成功后**不要手动关闭页面**，应用每秒检查一次登录态；检测到后自动关闭并开始加载目录。

预期：

- 页面表单完整可见（账号、密码、协议勾选、登录按钮）。
- 登录成功后 1–3 秒内自动返回应用。
- 加载完成后显示“已加载 N 本教材”（真实目录约 3500+ 本），并出现年级/学科筛选。

### 2.2 手工 Token（网页登录被平台限制时）

1. 在电脑上运行原版 TextbookGo 完成一次登录。
2. 打开用户目录下的 `token.json`：
   - Windows：`%USERPROFILE%\.config\BoooookDown\token.json`
   - macOS/Linux：`~/.config/BoooookDown/token.json`
3. 复制其中 `token` 字段的值。
4. 应用登录弹窗右上角点“手动输入” → 粘贴 → “使用此 Token”。

预期：格式合法时按钮可用；保存后进入已登录状态并加载目录。Token 等同登录凭据，不要发给他人。

未登录但本机已有目录缓存时，书单会被遮罩覆盖，只能浏览、不能选书；点“立即登录”即可：

![未登录遮罩](<images/verify-mask.png>)

## 3. 目录与选书

![真实目录](<images/verify-catalog.png>)

> 上图：真实平台目录加载完成（本次为 3565 本），年级/学科/版本筛选与封面均来自平台。  
> 界面用颜色区分维度：年级=蓝、学科=赭、版本=绿；选中项为实色高亮，未选中为同色描边。下图示例中版本行选中“人教版”：

![版本筛选](<images/verify-versions.png>)

1. 切换年级：只应出现真实年级（一年级…高三、高中），不应出现“中国历史/世界历史”或“一至二年级”这类非年级项。
2. 切换学科：前几项为数学、语文、英语、物理、化学、生物学，其余在后面。
3. 切换版本：默认“全部”，第二项固定为“人教版”，其余按教材数量排序。
4. 版本记忆：数学选“人教版”→切到没有该版本的语文（应回落“全部”）→再切回数学，应恢复“人教版”；在数学里显式选“全部”后再切走、切回，应保持“全部”。
5. 确认书名不再带“义务教育教科书”前缀；封面左上角有“2022年”标签的书应排在当前分类最前面，且书名里不再出现“（根据2022年版课程标准修订）”。
6. 连续选择 2–3 本（可跨年级/学科/版本），确认底部“已选 N 本”累加；清空可用。
7. 把年级/学科/版本任意一行横向滑到靠后的选项，切去“书架”再切回“下载”，三行的横向位置应保持，不需要重新滑。
8. 版本记忆：在七年级选“语文 + 统编版”，切到八年级（应恢复该年级上次的学科/版本），再切回七年级，应恢复“语文 + 统编版”；反向再测一次“数学 + 人教版”。

## 4. 下载与续传

1. 选 1 本页数适中的教材 → “开始下载”。
2. 首次下载会弹出通知权限请求（Android 13+）→ 允许。
3. 观察：
   - 自动跳到书架页；
   - 书架顶部出现“下载任务”卡片，显示“下载中”和真实字节进度；
   - 通知栏出现进度通知。
4. **暂停/继续**：任务卡片点“暂停”，确认进度停住；点“继续”，确认从已下载字节续传（不从头开始）。
5. **后台**：按 Home 键或锁屏 1–2 分钟，回来确认任务仍在继续（前台服务保活）。
6. **取消**：对另一个任务点“取消”，确认任务停止且 `filesDir/books/{bookId}.part` 被清理。
7. **失败重试**：临时开飞行模式再关闭，或对失败任务点“重试”，确认可恢复。

预期：完成后任务卡片自动消失，该书直接出现在书架。

## 5. 书架操作

1. 点封面右上角“⋮”：
   - **打开**：调用系统 PDF 应用；无可用应用时提示“未找到可打开 PDF 的应用”。
   - **分享**：系统分享面板出现，能分享到其他应用。
   - **导出**：系统文件选择器（SAF）选择目标位置，提示“已导出《…》”；导出的副本卸载应用后仍保留。
   - **删除**：弹出确认说明；确认后书架与文件同时删除。
2. 返回下载页，确认已下载的教材显示“已下载”，再次选择不会重复下载。
3. 封面应显示该教材的平台封面；若平台图不可用，会显示 PDF 首页缩略图（下载完成即生成），不再是空白。

## 6. 重启与状态恢复

1. 下载进行中强制停止应用（最近任务划掉或系统设置里“强行停止”）。
2. 重新打开：
   - 已登录状态自动恢复（未关闭“记住登录状态”时）；
   - 目录直接出现（缓存命中，无需重新加载）；
   - 未完成任务回到队列并继续/可重试；
   - 书架内容完整。

## 7. 设置与退出

1. 设置页“暗色模式”分别选“浅色 / 深色 / 跟随系统”，确认主题即时变化；杀进程重开仍保持（默认跟随系统）。
2. 关闭“记住登录状态” → 退出登录 → 杀进程重开，确认回到未登录页。
3. “登录状态”“构建类型（verify）”“存储路径”显示正确。
4. 关于页显示“作者：Yizhixx”“原作者：Wing900 · MIT License”和移植说明；“原项目 GitHub”可跳转上游仓库，“MIT 许可”弹窗能看到完整许可证。
5. 点“检查更新”：当前已是最新版时应提示“已是最新版本”；把 `update/latest.json` 的 `versionCode` 临时改成大于当前值后，应弹出新版本说明，可“稍后/跳过此版本/立即更新”。
6. 退出登录后，下载页仍可浏览缓存目录，但底部下载按钮禁用并提示重新登录。

## 8. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 点登录后页面空白/白屏 | 网络无法访问 `auth.smartedu.cn`，或平台拦截 WebView | 换网络重试；改用手工 Token |
| 登录页只显示一半表单 | 平台页面改版导致窄屏布局变化 | 已内置修正脚本；若仍异常，用手工 Token，并反馈页面截图 |
| 下载提示“平台拒绝访问（HTTP 403）” | 该教材需要账号权限/地区限制，或登录态失效 | 先在平台网页确认账号能看到该书；重新登录后再试 |
| 下载提示“登录已过期，请重新登录” | 凭据被平台判定失效 | 重新登录；任务可在登录后“重试” |
| 下载一直没有进度 | 私有 CDN 不可达/被网络限制 | 换 Wi-Fi/网络；查看书架顶部任务卡片的错误信息 |
| 通知栏没有进度 | 未授予通知权限 | 系统设置 → 应用 → TextbookGo → 通知，允许 |
| 锁屏后下载停止 | 厂商省电策略 | 设置电池优化为“不限制”，并反馈机型 |
