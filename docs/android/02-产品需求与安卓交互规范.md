# 02 产品需求与安卓交互规范

[返回文档入口](<README.md>) · **v0.2：Q1–Q6 已由用户于 2026-10-31 确认；其余明确标为建议或待确认的细节不视为一并批准。**

## 1. 产品定位与约束

TextbookGo 是面向学生、家长、教师等普通用户的教材获取和本地管理工具；以用户在国家智慧教育平台合法取得的访问权限为基础。目标是让“找教材 → 选教材 → 下载 → 找到文件”在手机上连贯完成。

**[要求]** 产品名 TextbookGo，目标工程名 TextbookGo-Mobile；仅本轮新增需求文档，不直接开发 App。

**[已确认：Q1/Q2]** Kotlin + Compose 原生实现，Android 8.0/API 26 起，手机优先，横屏/平板保证基本可用，增强布局后续做。target/compile SDK 另按实测兼容性锁定。首版简体中文、单设备本地使用、不自建账户/云后端为实施建议。

“风格不变”保留色彩、插画、封面比例、留白节奏和轻动效；“安卓习惯”调整导航、触摸、返回、文件入口、权限与后台任务，不保留桌面拖拽和悬停依赖。

## 3. 用户主链路

```text
启动 → 读取本地设置/书架/任务
 ├─ 可直接进入书架与设置（不强制联网登录）
 └─ 下载页 → 校验现有会话 / 打开官方授权页面
              → 目录获取 + 样本详情预检
              → 年级 → 学科 → 搜索/多选
              → 创建唯一任务快照 → 切到书架
              → 进度摘要 / 任务详情 → 校验成功逐本入架
              → 系统打开方式 / 导出 / 分享 / 删除
```

进程重建后从持久任务恢复；UI 不重建一个“看似全新”的下载队列。退出登录不删除已下载教材；取消授权也不影响离线书架。

## 4. 导航与安卓行为

### 4.1 一级导航

**[建议]** 手机底部 NavigationBar：**下载 / 书架 / 设置**，沿用原有三个一级入口和方线图标。选中态用克制墨色/浅填充，不使用默认高饱和紫色主题。书架数量徽标反映可用本地教材数，不混入失败/临时任务。

较宽设备可切 NavigationRail，但首版不依赖专属双栏完成任务。Edge-to-edge 处理状态栏、导航栏、刘海和 IME inset；底部主按钮不能被手势条/键盘覆盖。

### 4.2 返回优先级

1. 关闭当前键盘、弹窗或底部面板。
2. 退出书架管理多选/临时操作模式。
3. 授权 Web 页面内优先网页历史返回；离开授权页向用户确认取消，不提交凭据。
4. 从任务详情/文件详情等二级页面回到原页，保留筛选与滚动位置。
5. 一级“书架/设置”返回默认“下载”入口；一级下载返回按系统默认退到后台，不做“再按一次退出”的强制行为。

以上导航回退为建议，实施时与 Navigation 状态恢复、预测返回一起测试；返回不应无提示取消后台下载。

## 5. 页面规格

### P01 下载入口 / 登录预检

- 顶栏：TextbookGo 或“下载”；会话状态显示“未登录 / 需验证 / 已验证 / 已过期”，不因本地有字符串就显示有效。
- 主卡：原“坠书一瞬”几何插画、简短用途、官方平台提示、主按钮“登录并加载教材”。已有凭据时显示“校验并加载教材”。
- 本地书架和设置始终可进入；首次启动先说明需要访问第三方平台与文件保存方式，不提前申请全盘权限。
- 点击后禁用重复操作并分阶段显示“等待授权 / 获取目录 / 校验资源权限”。取消、超时和网络错误均恢复可操作按钮。
- 无缓存目录时加载失败显示重试；有完整缓存时允许“使用缓存浏览”，提示更新时间，下载前验证会话。
- 不复制桌面 10 秒无意义倒计时；5 分钟授权超时可作为初始建议值，可手动退出。

### P02 平台授权页

- 正式路线先验证平台支持的官方重定向授权；不能因为 Custom Tabs 能打开就认定可以获得 token。
- 如获允许并验证可用的嵌入式 WebView 路线被采用，顶部必须有可信来源提示、关闭和加载状态，验证码/短信/扫码由平台原页处理。
- App 不自建仿官方账号密码表单，不要求用户提供密码给开发者，不忽略证书错误，不承诺同屏扫码可用。
- 登录成功必须完成资源预检后返回选书；页面加载成功不等于授权成功。
- 未解决合法授权前只交付 PoC 结论，不把手动粘贴 token 作为首版默认用户体验。

### P03 选书页

推荐手机结构：

```text
┌ 下载                         会话状态 ┐
│ 年级：七年级 ▾    学科：数学 ▾       │
│ 搜索当前年级/学科的书名               │
│ ┌封面────┐   ┌封面────┐          │
│ │        │   │        │          │
│ └标题/状态┘   └标题/状态┘           │
│             可垂直滚动               │
│ 已选 3 本 · 查看   清空   下载(3)    │
├ 下载          书架          设置 ┤
└──────────────────────────────┘
```

- 为避免学科多时 chip 云占满屏，年级/学科各用一行当前值，点击打开可滚动选择面板；少量学科时可使用紧凑 Chips。面板仍沿用纸张色、低饱和选中态。
- 默认第一个年级和其第一个学科；无学科显示空态，不能沿用上个年级的旧学科形成隐性筛选。
- 年级与学科规则对齐源码；暂不引入版本/册次筛选器，但可在标题下作为元信息展示。
- 列表采用 LazyVerticalGrid，常规手机默认 2 列；宽度/字体不够时允许 1 列，不能为维持密度截断所有关键信息。
- 点卡片切换选中，不跳回顶部；轻量边框、勾选与状态文字共同表达选中，不只靠颜色。
- 搜索是当前分类内，切分类保留查询时明确显示搜索词；输入框有清除入口。新增全局搜索须另立需求。
- 跨分类选择保留；点“已选 N 本”打开清单，可看全标题和分类、单项移除。**底部 N、清单 N、唯一提交 ID 数必须一致。**
- 已下载卡片允许进入已选清单但标注“已下载，将跳过”；也可由你确认后改为不可选择，不能未说明改变旧体验。
- 无选择时主按钮禁用；快速连续点下载只创建一个批次。
- 创建任务成功后才切书架；创建失败留在原页且保留选中，不把错误写进隐藏页面。

### P04 书架

- 延续封面网格、标题和文件信息，默认按完成时间稳定排列；具体新书置前还是追加需在视觉基线评审确定。旧版历史为追加顺序。
- 可用文件数为空时展示原几何“落架”插画与“去下载”按钮。
- 点击教材 **[已确认：Q3，首版不内置阅读器]** 使用系统 `ACTION_VIEW` 打开 PDF；无处理 App 则提示安装阅读器，并保留导出入口。这是安卓可用性补充，不是旧版已有内置阅读器。
- 卡片溢出菜单或长按面板：完整标题/文件信息、打开、分享、导出、删除。删除不能只通过手势发现。
- [已确认：Q4] 删除确认说明“删除 App 内教材文件及书架记录”；已导出的独立副本不连带删除，首版不提供公共目录作为主存储的模式。
- 文件访问暂时失败显示“无法访问，检查位置/授权”，不直接抹去书架记录。确认为文件缺失则提供“重新下载 / 移除记录”。
- 下载中不把未完成 PDF 放入可打开书架，另用任务摘要区域呈现，逐本完成逐本入架。
- 保留当前选中/滚动锚点，不因一本新书完成而重建整个页面。

### P05 下载任务面板 / 详情

- 手机不使用桌面固定右下角 300px 悬浮框；用书架底部可折叠摘要，点击打开 ModalBottomSheet 或详情页。
- 收起态显示“进行中 X / 已完成 Y / 失败 Z”，导航切走后仍有统一任务入口。
- 每行显示全/可展开标题、状态、已传输大小，已知总量显示百分比，未知总量显示不确定进度。
- 失败行保留原因和“重试”；提供单任务取消，批次取消需明确说明；重试不能产生重复成功文件。
- [已确认：Q5] 排队/解析/传输任务可“暂停”，完成安全落盘后释放传输槽并保留临时文件；用户点“继续”才恢复。网络恢复或 App 重启不得自行恢复主动暂停任务。满足 Range/资源校验条件才追加，否则提示“无法安全续传，将重新下载”。校验/提交关键阶段不提供即时暂停。
- **完成**指本批任务进入终态；不能把“全部结束”写成“全部成功”。成功、跳过、失败、取消分开计数。
- 原版完成后自动隐藏面板；安卓成功摘要可淡出，但失败/取消记录应保留到用户处理或明确清除。
- 后台由系统通知展示任务状态，点击回任务页；拒绝通知权限时仍在 App 内显示，不以此要求用户放弃下载。
- 后台因会话过期进入“等待重新登录”，不能后台强行拉起授权页。

### P06 设置

| 项目 | 建议行为 |
|---|---|
| 外观 | 晨光 / 夜读，DataStore 持久化；跟随系统为可选增强 |
| 记住登录状态 | 默认开启；关闭先解释影响，清除持久凭据，当前内存授权可继续，后续授权也不落盘 |
| 退出登录 | 与“不记住”分离；清内存/持久凭据及已批准的 WebView 会话，保留教材；受保护任务转需登录 |
| 下载位置 | 已确认 App 内保存＋按需导出；展示空间/导出入口及“卸载会删除未导出的教材”说明；首版无主存储切换 |
| 下载后自动打开目录 | 不照搬；建议删除该开关，改为完成通知 + 点击查看，不后台强开页面 |
| 通知 | 显示权限现状，可跳系统设置；不开启也能看到应用内任务 |
| 关于/隐私/开源 | App 版本、原作者 MIT 归属、教材版权/用途、第三方平台说明 |

“删除或替换自动打开目录”属于 Android 交互变更，需你确认。若坚持保留，仅允许 App 前台且用户启用时打开可用文件入口，后台仅发通知。

### 6.1 颜色与组件

| 语义 | 晨光 | 夜读 |
|---|---|---|
| 页面底 | `#F9F8F5` | `#121211` |
| 卡片 | `#FFFFFF` | `#1A1918` |
| 柔和表面 | `#F2F1EC` | `#1F1E1C` |
| 主文字 | `#1C1B1A` | `#E4E2DC` |
| 次文字 | `#4A4845` | `#B5B2A9` |
| 弱文字 | `#82807C` | `#7A7873` |
| 点缀/下载进度 | `#5B6B5F` | `#8FA096` |
| 拼贴 linen/sage | `#E8E4D9` / `#A7B0A0` | `#3A382F` / `#4A544C` |
| 拼贴 terracotta/basalt | `#C09A86` / `#6B7079` | `#6E4A3C` / `#4A4F58` |
| 拼贴 oatmeal/ink | `#D4C9B0` / `#2A2926` | `#5A513D` / `#D6D4CD` |

- 主按钮沿用墨色背景与纸色文字，不误把所有 CTA 改为苔绿色。苔绿主要用于点缀、选中和进度。
- 封面比例 `148:200`、直角；保留两块色面 + 一条墨线/墨点的 6 种确定性拼贴。按 ID 的 UTF-16 单元做 `h = (h * 31 + codeUnit) mod 2^32`，再 `%6`，保证与 JS 一致。
- 圆角层级参照 10/14/20/28，按钮胶囊；转换为 dp 后以实际手机评审为准，不把网页 px 生硬当 sp。
- 页面边距建议 16dp，组件间距 8/12/16/24dp；触控目标至少 48dp。
- 标题保留衬线气质，正文使用系统 sans。Android 中文衬线显示依赖字体，不能假定设备有桌面字体；如需打包字体，另核许可、体积和字重。
- 不默认启用系统动态配色，以免改变品牌；无 emoji 替代功能图标。
- 轻噪点可做低成本静态纹理；背景呼吸、封面轻倾斜是可裁剪装饰，不牺牲帧率与省电。

### 6.2 动效与可访问性

- 快/常规/慢动效参考 160/240/420ms；下载条更新去抖，列表仅新增项轻入场，不整体重放。
- 禁用系统动画/省电时停止持续呼吸与不必要位移；不要把交互是否完成依赖动画结束事件。
- TalkBack 读出完整书名、选中/已下载、按钮语义、下载状态；封面本身装饰性时不重复朗读。
- 正文支持字体缩放，测试 1.0/1.3/2.0；弱文字不直接用作小字号关键状态，需实测对比度并适度调整。
- 原音效不强制保留；Android 使用系统点击反馈或轻触觉，尊重系统设置，不自行持续发声。

## 7. 状态与文案最低要求

| 状态 | 用户看到什么 | 可执行动作 |
|---|---|---|
| 无网且无目录 | “暂时无法获取教材目录，本地教材仍可使用” | 重试/去书架 |
| 缓存目录 | 缓存日期、可能不是最新 | 刷新/继续浏览 |
| 部分分片失败 | “目录更新不完整”，不能假装全部加载 | 重试/用上次完整目录 |
| 会话失效 | “登录已过期，下载等待授权” | 前台重新登录/取消任务 |
| HTTP 403 | “暂无该资源访问权限” | 返回/查看说明，不反复登录 |
| 429 | “请求过于频繁，稍后重试” | 等待/取消，不绕过限制 |
| 未知文件大小 | 不确定进度 + 已传输字节 | 取消 |
| 空间不足 | 所需/可用空间（能得知时） | 清理/换位置/重试 |
| URI 授权失效 | “保存位置授权已失效” | 重新授权/导出到其他位置 |
| 文件校验失败 | “文件不完整，未加入书架” | 重试/清理临时文件 |
| 没有阅读器 | “未找到可打开 PDF 的应用” | 分享/导出/取消 |

## 8. 补充非功能需求（建议验收基线）

1. 本地书架不依赖网络、会话或上游目录可用；冷启动不主动弹出授权。
2. 下载不把整个 PDF 装入内存；使用 500MB 自建文件测试，下载缓冲不随文件大小增长；总 RSS 另外测量，不能仅凭缓冲大小声称“无限大文件”。
3. 大目录使用懒加载/数据库分页；1,000 条假目录下滚动和筛选无主线程磁盘或网络阻塞。
4. 主线程无文件复制、PDF 渲染、JSON 大解析；StrictMode debug 下可检查。
5. 日志不含 token、cookie、账号、受保护 URL 参数；凭据排除备份和崩溃报告。
6. 文件不会因重试/同名/并发损坏；进程重建后持久任务与真实文件可核对。
7. 目标设备上的启动/内存/帧率预算由 M0 冻结；建议中端真机离线书架可交互 ≤2 秒，但不把网络目录总耗时承诺为 2 秒。
