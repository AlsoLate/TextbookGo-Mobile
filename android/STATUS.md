## 4. 与规划的偏差

| 项 | 规划 | 当前实现 | 原因/影响 |
|---|---|---|---|
| 持久化 | Room | 原子 JSON + DataStore | 降低收尾风险、便于 JVM 测试；数据量/并发增长后迁移 Room |
| 后台 | 前台服务/WorkManager + 通知 | 前台服务 + 进度通知 | 已有保活与通知；锁屏/厂商省电策略仍要真机验证 |
| 授权 | 官方授权/受控 WebView | 应用内 WebView 读取平台登录态 + 手工 token | 与旧版桌面端一致；平台若改版需同步更新选择器 |
| 凭据落盘 | Keystore 加密 | 应用私有 JSON（关闭备份） | 未 root 设备上等价于应用私有；后续可换 Keystore 实现 |
| PDF 封面 | PdfRenderer 首页 | 确定性几何拼贴 | 首版视觉可用；缩略图可后续补 |
| 书签 | pdfcpu/库写入 | 仅核心映射 | 可选增强，未阻塞首版客户端 |
| 分发 | APK 内测 | Debug/verify 可安装；release 未签名 | verify 用调试签名，专供真机验收 |

## 5. 已知风险

1. **真实下载未验证**：无账号环境只能验证到“目录 + 登录页 + 鉴权失败路径”。第一次用真实账号跑通前，不能宣称端到端可用。
2. **登录页依赖 WebView 兼容性**：平台页面按大屏设计，已注入脚本把登录框移回视口；平台改版可能导致选择器失效。
3. **403 语义**：详情接口对部分教材返回 403，可能是账号权限/地区限制，不一定是登录失效；界面提示已同时给出两种可能。
4. **大目录内存**：4 个分片约 40 MB JSON，串行/两路并发解析；低端机峰值内存需关注。
5. **重定向策略**：客户端关闭自动重定向，下载层手动跟随且只允许平台域名；遇到新 CDN 域名需加白名单。
6. **JSON 存储并发**：单进程内使用 Mutex，跨进程/多实例未定义；迁移 Room 时统一。
7. **视觉/无障碍**：仅结构 token 对齐，未做像素级与 TalkBack 全量走查。

## 6. 交接要点

- 装配入口：`AppContainer`（`app/src/main/.../AppContainer.kt`）。
- 平台差异：`Bindings.create` 由 `src/debug`（示例）、`src/verify` 与 `src/release`（共用 `RealPlatformBindings`）提供。
- 授权实现：`StoredAuthRepository` + `TokenStore` + `WebLoginDialog`；凭据只存 `filesDir/auth-token.json`（`allowBackup=false`）。
- 数据位置：`filesDir/books/`、`filesDir/shelf.json`、`filesDir/tasks.json`、`filesDir/catalog-cache.json`、DataStore `textbookgo-settings`。
- 下载保活：`download/DownloadService`（前台服务，无任务时自动停止）。
- 测试入口：领域 `core/src/test`，数据层 `app/src/test`，设备级 `app/src/androidTest`。
- 真机验收：按 `docs/android/05-真机验收指南.md` 执行。
